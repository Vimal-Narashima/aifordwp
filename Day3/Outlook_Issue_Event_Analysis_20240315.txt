What each Event ID records

1. Event ID 1000 (Source: Application Error)
Records an application crash at process level.
In your entries it shows Outlook crashed, where Windows detected the fault in KERNELBASE.dll, with exception code 0xc0000005 (access violation), and the same fault offset each time.

2. Event ID 1001 (Source: Windows Error Reporting)
Records that Windows Error Reporting created a crash report for that failure.
APPCRASH and a fault bucket ID are used to classify and group similar crashes across devices/builds.

3. Event ID 1026 (Source: .NET Runtime)
Records a .NET unhandled exception that terminated the process.
Here it is System.AccessViolationException, which aligns with invalid memory access during Outlook execution.
