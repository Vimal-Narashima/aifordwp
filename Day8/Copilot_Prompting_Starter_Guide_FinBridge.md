# Copilot Prompting Starter Guide (FinBridge)

Audience: Non-technical office staff  
Purpose: Help you get useful results from Microsoft 365 Copilot quickly and safely

## Start Here: The 5-Part Prompt Formula

Use this simple pattern every time:

**Task + Context + Output + Tone + Checks**

- **Task**: What you want Copilot to do
- **Context**: The source (email thread, document, table, date range, meeting notes)
- **Output**: The format you want (bullet list, email draft, table, summary)
- **Tone**: Friendly, formal, concise, etc.
- **Checks**: Anything to watch for (missing data, action owners, deadlines)

### Quick reusable template

"Please **[task]** using **[context]**. Return it as **[output format]** in a **[tone]** tone. Flag **[checks/risks/missing info]**."

Example:

"Please draft a reply to this client update email using the thread below. Return it as a short email with 3 clear next steps in a professional and warm tone. Flag any unanswered questions."

## Outlook: Prompt Examples You Can Use Today

### 1) Triage a busy inbox

"Review my emails from the last 24 hours and group them into: Urgent, Today, and This Week. For each urgent item, suggest a one-line reply and a proposed due date."

### 2) Draft a clear client follow-up

"Draft a follow-up email to the client based on this conversation. Thank them for the update, confirm we are reviewing their request, and ask for any missing documents. Keep it under 120 words and use a professional, friendly tone."

### 3) Prepare for a meeting from an email thread

"Summarise this email thread into 5 bullets: objective, current status, open questions, key dates, and who needs to do what before Friday."

---

## Word: Prompt Examples You Can Use Today

### 1) Turn rough notes into a polished document

"Use these notes to create a one-page status update with headings: Summary, Progress This Week, Risks, and Next Steps. Keep the language plain and suitable for senior managers."

### 2) Rewrite for clarity and tone

"Rewrite this draft so it is clearer and easier to read for non-specialists. Use short paragraphs, remove jargon, and keep the meaning the same."

### 3) Create an executive summary quickly

"Read this document and produce a 6-bullet executive summary covering: purpose, key findings, financial impact, risks, decisions needed, and deadline."

---

## Excel: Prompt Examples You Can Use Today

### 1) Explain what changed in the numbers

"Compare this month's figures with last month's and summarise the 5 biggest changes in plain English. Show what went up, what went down, and possible reasons based on the headings in the sheet."

### 2) Build a simple tracker view

"From this sheet, create a clear action tracker with columns for Owner, Task, Due Date, Status, and Priority. Highlight overdue items and sort by due date."

### 3) Spot unusual numbers and missing entries

"Check this table for duplicate rows, empty cells, and any numbers that look unusually high or low. Give me a short list of what to fix first."

## What Makes a Prompt "Good"?

If your first result is not right, do not start over. Improve it by adding one missing detail:

- Add a clearer task ("compare", "summarise", "draft", "rewrite")
- Add clearer context (for example: date range, exact table, or section)
- Add an output style (word count, bullets, headings, table)
- Add a simple check ("point out missing information" or "show anything unclear")

A second prompt often gives a much better result than the first.

## Day 1 Data-Safety Habit (Important)

This is here to keep you safe, not to stop you using Copilot.

Before you paste anything into an AI tool, pause and ask:

**"Does this contain confidential client data, personal data, or secrets?"**

- In **Microsoft 365 Copilot** (inside approved FinBridge systems), follow company policy and only use data you are authorised to access.
- In **external AI tools**, do **not** paste confidential client information, personal data, passwords, account numbers, or internal sensitive details.
- If needed, anonymise first (for example: replace real names with CLIENT_A).

If you are unsure, pause and ask your manager, security lead, or data protection contact before pasting.

## 30-Second Prompt Checklist

Before pressing Enter, check:

- Did I say exactly what I want done?
- Did I give enough context?
- Did I ask for the format I need?
- Did I set the right tone for the audience?
- Did I avoid sharing sensitive data in the wrong place?

This habit will improve quality and reduce rework.
